# Техническое задание: CLI утилита "guru"

## Описание
CLI утилита для анализа CLAUDE.md и формирования эффективных структурированных промптов для Claude Code.

## Основные характеристики

| Параметр | Значение |
|----------|----------|
| Язык | Python 3.9+ |
| Название команды | `guru` |
| Дистрибуция | PyPI (`pip install talk-as-guru`) |
| Режим работы | REPL (интерактивный) |
| UI | Цветной (rich) |

## Функциональные требования

### 1. Базовый флоу
```
Пользователь запускает: guru
Утилита читает ./CLAUDE.md и кэширует
Ожидает ввод запроса
Формирует структурированный промпт
Сохраняет в ./prompts/prompt_01.md
Ждёт следующий запрос
```

### 2. Поиск CLAUDE.md
- Искать только в текущей директории: `./CLAUDE.md`
- При отсутствии — вывести ошибку и предложить создать

### 3. Формирование промпта
Шаблон с подстановкой. Структура выходного файла:

```markdown
# Задача
[запрос пользователя]

# Стек технологий
[извлечь из CLAUDE.md]

# Конвенции проекта
[извлечь из CLAUDE.md]

# Ограничения и правила
[извлечь из CLAUDE.md]

# Контекст
[релевантные части CLAUDE.md]
```

### 4. Сохранение результатов
- Папка: `./prompts/`
- Имя файла: `prompt_01.md`, `prompt_02.md`, ... (автоинкремент)
- Создавать папку автоматически при отсутствии

### 5. Команды REPL
| Команда | Описание |
|---------|----------|
| `/reload` | Перечитать CLAUDE.md |
| `/history` | Показать историю запросов |
| `/template [name]` | Переключить шаблон |
| `/profile [name]` | Загрузить профиль проекта |
| `/run` | Отправить последний промпт в Claude Code |
| `/help` | Справка по командам |
| `/exit` или Ctrl+C | Выход |

### 6. Настраиваемые шаблоны
- Хранить в `~/.guru/templates/`
- Формат: Jinja2 или простые плейсхолдеры
- Шаблон по умолчанию встроен в пакет

### 7. Профили проектов
- Хранить в `~/.guru/profiles/`
- Содержат: путь к CLAUDE.md, шаблон, настройки парсинга
- Автоопределение профиля по текущей директории (опционально)

### 8. Интеграция с Claude Code CLI
- Опциональная отправка промпта напрямую в `claude` CLI
- Команда `/run` или флаг `--run` — сформировать промпт и сразу выполнить
- Использует подписку пользователя (Claude Max/Pro)
- Вызов: `claude --print "промпт"` для получения ответа
- Вывод ответа в терминал + сохранение в файл

## Технические требования

### Зависимости
- `rich` — цветной вывод и форматирование
- `click` или `typer` — CLI framework
- `pyyaml` — конфигурация и профили

### Структура проекта
```
talk-as-guru/
├── src/
│   └── guru/
│       ├── __init__.py
│       ├── cli.py           # Точка входа
│       ├── parser.py        # Парсинг CLAUDE.md
│       ├── prompt_builder.py # Формирование промптов
│       ├── repl.py          # REPL-цикл
│       ├── templates/       # Встроенные шаблоны
│       └── config.py        # Работа с конфигами
├── pyproject.toml
├── README.md
└── tests/
```

### Entry point
```toml
[project.scripts]
guru = "guru.cli:main"
```

## Интерфейс

### Запуск
```bash
guru                    # Запуск REPL
guru "создай API"       # Однократный запрос (без REPL)
guru --help             # Справка
```

### REPL-сессия
```
$ guru
🔮 Guru v0.1.0 | CLAUDE.md загружен (2.3 KB)

guru> создай REST API для управления пользователями

✅ Сохранено: ./prompts/prompt_01.md

guru> /run
🚀 Отправляю в Claude Code...
[ответ от Claude]

guru> /history
1. создай REST API для управления пользователями

guru> /exit
👋 До встречи!
```

## Этапы реализации

1. **MVP** — базовый REPL, парсинг CLAUDE.md, простой шаблон
2. **Команды** — /reload, /history, /help
3. **Claude CLI** — интеграция с `claude` через /run
4. **Шаблоны** — настраиваемые шаблоны
5. **Профили** — поддержка профилей проектов
6. **PyPI** — публикация пакета

## Верификация

1. `pip install -e .` — установка в dev-режиме
2. Запустить `guru` в директории с CLAUDE.md
3. Ввести тестовый запрос
4. Проверить создание `./prompts/prompt_01.md`
5. Проверить структуру и содержимое файла
6. Протестировать команды `/reload`, `/history`, `/exit`
7. Протестировать `/run` (требует установленный `claude` CLI)
